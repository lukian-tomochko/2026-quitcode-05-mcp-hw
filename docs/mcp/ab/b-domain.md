● У LeadDesk п'ять статусів, інших немає.

  ┌───────────┬──────────────────────────────────────────────────────────────┐
  │  Статус   │                    Що означає для команди                    │
  ├───────────┼──────────────────────────────────────────────────────────────┤
  │ new       │ Заявка прийшла з форми чи кампанії, ніхто з команди ще не    │
  │           │ зв'язувався з клієнтом. Це початковий статус кожного ліда.   │
  ├───────────┼──────────────────────────────────────────────────────────────┤
  │           │ Менеджер уже говорив із клієнтом: був дзвінок або            │
  │ contacted │ персональний лист, і є відповідь або зафіксована спроба.     │
  │           │ Автовідповідь не рахується, такий лід лишається new.         │
  ├───────────┼──────────────────────────────────────────────────────────────┤
  │           │ Після розмови відомі потреба, орієнтовний бюджет і термін, а │
  │ qualified │  контакт має право вирішувати. Без названого бюджету лід не  │
  │           │ кваліфікують.                                                │
  ├───────────┼──────────────────────────────────────────────────────────────┤
  │           │ Клієнт підтвердив співпрацю: підписано договір або отримано  │
  │ won       │ передоплату. У won лід переводить лише власник (owner), не   │
  │           │ менеджер.                                                    │
  ├───────────┼──────────────────────────────────────────────────────────────┤
  │ lost      │ Клієнт відмовився, або за 14 днів після трьох спроб зв'язку  │
  │           │ відповіді немає. Причину в reason пишуть завжди.             │
  └───────────┴──────────────────────────────────────────────────────────────┘

  Правила зміни статусу
  - Статус зазвичай рухається вперед: new → contacted → qualified → won. У lost
    лід можна перевести з будь-якого статусу.
  - Кожна зміна потрапляє в аудит із причиною (reason, 3–500 символів). Причина
    має бути по суті, наприклад «клієнт підтвердив бюджет 3000 USD у дзвінку», а
    не «ок».
  - Повернути лід із lost у роботу можна лише за прямою вказівкою людини.
  - Перед зміною статусу я називаю лід, новий статус і причину та чекаю вашого
    підтвердження.

  Ці правила пояснюють дані з ваших попередніх запитів. Лід lead_0006 (Nova
  Dental) має статус won без бюджету. Перевірка бюджету за правилами стосується
  переходу в qualified, тому це не обов'язково помилка.
